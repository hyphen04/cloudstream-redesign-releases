# CloudStream+

A personal build of [CloudStream](https://github.com/recloudstream/cloudstream) with a redesigned phone UI.
It is rebuilt automatically whenever the official app changes. The app's built-in updater checks this repo's releases.

- Install: download the latest `CloudStream-Plus-*.apk` from [Releases](../../releases/latest).
- It installs alongside the official app (package `com.kunj.cloudstreamplus`). Move your data across with Settings → Backup / Restore.
